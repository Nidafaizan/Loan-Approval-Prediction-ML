# Loan-Approval-Prediction-ML
Machine Learning model using Python and Random Forest to predict loan eligibility based on applicant data.
# Loan Approval Prediction System

## Project Overview
This project involves building a classification model to predict whether a loan application will be approved based on various applicant details. This is a critical tool for financial institutions to automate the lending process while maintaining high precision.

## Key Features
- **Exploratory Data Analysis (EDA):** Visualized relationships between credit history, income, and loan status.
- **Data Preprocessing:** Handled missing values and encoded categorical variables.
- **Feature Engineering:** Created 'TotalIncome' to better assess household repayment capacity.
- **Machine Learning:** Implemented a Random Forest Classifier with hyperparameter tuning.

## Results
- **Accuracy:** ~79%
- **Precision:** ~76%
- **Insights:** Credit History was identified as the most significant factor in loan approval.

## Technologies Used
- Python (Pandas, NumPy, Scikit-Learn)
- Seaborn & Matplotlib for Visualization
